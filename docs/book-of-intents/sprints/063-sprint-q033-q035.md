# Sprint 063: Q-033(b) staged read-model rollout + Q-035(a) content-addressed geometry

**Date:** 2026-11-27 · **Status:** code + local gates complete; founder authorized
commit/merge to `main` · **Exit gate:** all IDL account types produce a
chain-derived, provenance-tagged mirror; a chain-only parcel can be displayed
only from bytes whose content hash and ring hash both match the chain.

## Trigger

Q-033 offered either the eight typed mirror tables or a funded staged rollout
with per-type acceptance tests; Q-035 required a client-independent, honest
source of parcel geometry given `parcels.geometry IS NOT NULL` and an on-chain
`Parcel` that carries only `geometry_hash`. The founder chose Q-033(b) and
Q-035(a) and authorized commit/merge once the work was done.

## Scope and decisions

1. **Stage 0 (unchanged):** eight typed mirrors — Parcel, VerificationAttestation,
   Rights, Claim, SpatialAsset, GeometryVersion, ThreeDModel, SpatialSnapshot —
   with two-phase upserts for FK-dependent rows.
2. **Stage 1 (ADR-028):** `scripts/generate-indexer-decoders.py` derives a
   decoder for every account in `idl/terra_registry.json` and emits
   `ALL_ACCOUNT_NAMES`, `RICH_ACCOUNT_NAMES`, `decode_any()` and the full
   discriminator table. 82 per-type acceptance tests; CI pins the generated
   file with `--check`. `mirror_account()` calls `decode_any()` before typed
   dispatch and writes a generic `chain_accounts` row (migration 0060, applied)
   with ADR-026 provenance and a trigger-maintained `mirror_hash`. Later stages
   may promote a type to a typed table/API only with a decoder, mirror, hash and
   audit rule. `AccountProvenance::verified()` normalizes empty/whitespace
   signatures so no path can claim a real transaction from `Some("")`.
3. **Q-035(a) (ADR-029):** new on-chain `ParcelGeometryArtifact` PDA
   `["parcel_geometry_artifact", parcel, content_hash]` and instruction
   `register_parcel_geometry_artifact(content_hash, storage_uri)`. The `Parcel`
   Borsh layout is unchanged. Registration requires the current rights holder
   (identity-PDA overlay included), is idempotent for the same digest/URI and
   rejects a different URI for an existing digest. Migration 0061 (applied)
   adds the typed artifact mirror and `parcel_geometry_uploads`.
4. **Signed upload + materialization:** `PUT
   /api/v1/parcels/{parcel_pda}/geometry-artifact` stores raw GeoJSON under
   `sha256(bytes)` with a required `X-Content-SHA256` header and signed body
   hash. The indexer materializes a chain-only parcel only when the artifact
   row has a real tx signature, the on-chain URI equals the stored ref,
   `sha256(bytes) == content_hash`, and `sha256(JSON.stringify(coordinates[0]))
   == Parcel.geometry_hash`. Missing/failing checks leave the parcel invisible.
5. `/mirror/audit` covers `chain_accounts` and `parcel_geometry_artifacts` with
   hash SQL matching their triggers.
