# Terra Trademarks

The Apache-2.0 `LICENSE` covers the source code in this repository only. It
does not grant rights to Terra's names, logos, or branding.

## Covered marks

- The name **Terra** (and `terra-core`, `terra-web`, `terra_registry`,
  `terra_identity` as product identifiers)
- The Terra logo and wordmark used in `terra-web` and project materials

## What you may do without asking

- Use the code under Apache-2.0 however the license permits.
- Say that your project "uses Terra" or "is built on Terra" in plain text,
  without implying endorsement or official status.

## What needs permission

- Using the Terra name or logo as your own product, service, or project name.
- Implying that your deployment, fork, or service is the official Terra
  network, an official validator, or otherwise affiliated with the project.
- Registering domains, app-store listings, or trademarks that include the
  Terra marks.

## Deployments and validators

Running a Terra node, validator, or API against public networks is fine.
Presenting that deployment *as* Terra — with Terra branding, in a way a
reasonable person would read as official — requires written permission.

## Questions

Open an issue in this repository. Trademark policy may evolve as the project
approaches devnet/mainnet; this file is the current policy.
